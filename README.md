# CCRQS

Composite Code Review Quality Score (CCRQS) — исследовательский критерий оценки автоматизированного ревью Python-кода. Материалы показывают, как сопоставлять замечания с размеченными дефектами, оценивать качество комментария и проверять предложенные исправления.

## Быстрый старт

Требуются Python 3.12, pip и подключение к GitHub для загрузки закреплённого снимка QuixBugs. Выполните команды из корня репозитория. Для изолированной установки можно предварительно создать и активировать виртуальное окружение.

```sh
python -m pip install -r requirements.lock.txt
python examples/average/demo.py
python tools/fetch_quixbugs.py
python -m pytest tests
python pipeline.py run --config configs/smoke.json
python -m examples.quixbugs10.replay
```

Пример `average` генерирует четыре учебных ответа и проверяет их на одном дефекте. Smoke-прогон v8 использует синтетические ответы с эталонными патчами. Демонстрация на десяти задачах пересчитывает результаты по 20 подготовленным ответам, 40 учебным оценкам и сохранённым результатам выполненных тестов. Этот пересчёт работает офлайн после загрузки QuixBugs и установки зависимостей.
