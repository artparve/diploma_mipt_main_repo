# Разворачивание вложенного списка


## Шаг 1 Исходный код QuixBugs

```python
def flatten(arr):
    for x in arr:
        if isinstance(x, list):
            for y in flatten(x):
                yield y
        else:
            yield flatten(x)
```

Файл: `python_programs/flatten.py`. Номера строк замечаний относятся к полному исходному файлу; копия сохранена в `data/QuixBugs/python_programs/flatten.py`.

## Шаг 2 Что проверяющий знает об ошибке

Для элемента, не являющегося списком, выдаётся объект генератора вместо самого элемента.

Наглядный вход: `list(flatten([1, [2]]))`. Ожидается `[1, 2]`. Это поясняющий пример, а A/T/R ниже рассчитаны по тестам из зафиксированного манифеста.

В манифесте: 6 целевых и 1 регрессионных тестов. Эталон и тесты служат материалами оценивания.

## Шаг 3 Ответ Gemma

```text
В ветке else yield flatten(x) выдаёт объект генератора вместо исходного элемента. Для скалярного x следует выдавать сам x, иначе результат не является плоским списком.
```

Локализация: строка 7 исходного файла.

Предлагаемый patch:

```diff
--- a/python_programs/flatten.py
+++ b/python_programs/flatten.py
@@ -4,7 +4,7 @@
             for y in flatten(x):
                 yield y
         else:
-            yield flatten(x)
+            yield from flatten(x)
```

## Шаг 3 Ответ Qwen-Coder

```text
В else выдаётся flatten(x), то есть генератор, хотя x уже является не-списочным конечным элементом. Замените на yield x. Тогда list(flatten([1, [2]])) вернёт [1, 2].
```

Локализация: строка 7 исходного файла.

Предлагаемый patch:

```diff
--- a/python_programs/flatten.py
+++ b/python_programs/flatten.py
@@ -4,7 +4,7 @@
             for y in flatten(x):
                 yield y
         else:
-            yield flatten(x)
+            yield x
```
