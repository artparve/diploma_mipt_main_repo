# Наибольший общий делитель


## Шаг 1 Исходный код QuixBugs

```python
def gcd(a, b):
    if b == 0:
        return a
    else:
        return gcd(a % b, b)
```

Файл: `python_programs/gcd.py`. Номера строк замечаний относятся к полному исходному файлу; копия сохранена в `data/QuixBugs/python_programs/gcd.py`.

## Шаг 2 Что проверяющий знает об ошибке

Аргументы рекурсивного вызова перепутаны: второй аргумент не уменьшается.

Наглядный вход: `gcd(35, 21)`. Ожидается `7`. Это поясняющий пример, а A/T/R ниже рассчитаны по тестам из зафиксированного манифеста.

В манифесте: 5 целевых и 1 регрессионных тестов. Эталон и тесты служат материалами оценивания.

## Шаг 3 Ответ Gemma

```text
В рекурсивной ветке b остаётся тем же. После первого шага остаток может быть меньше b, и вызов повторяется бесконечно. Для алгоритма Евклида передавайте gcd(b, a % b).
```

Локализация: строка 5 исходного файла.

Предлагаемый patch:

```diff
--- a/python_programs/gcd.py
+++ b/python_programs/gcd.py
@@ -2,7 +2,7 @@
     if b == 0:
         return a
     else:
-        return gcd(a % b, b)
+        return gcd(b, a % b)
 
 
 """
```

## Шаг 3 Ответ Qwen-Coder

```text
Рекурсивный вызов gcd(a % b, b) не уменьшает второй аргумент. Нужно перейти к паре (b, a % b), иначе возникает повтор одного состояния и RecursionError.
```

Локализация: строка 5 исходного файла.

Предлагаемый patch:

```diff
--- a/python_programs/gcd.py
+++ b/python_programs/gcd.py
@@ -2,7 +2,7 @@
     if b == 0:
         return a
     else:
-        return gcd(a % b, b)
+        return gcd(b, a % b)
 
 
 """
```
