# Простые числа


## Шаг 1 Исходный код QuixBugs

```python
def sieve(max):
    primes = []
    for n in range(2, max + 1):
        if any(n % p > 0 for p in primes):
            primes.append(n)
    return primes
```

Файл: `python_programs/sieve.py`. Номера строк замечаний относятся к полному исходному файлу; копия сохранена в `data/QuixBugs/python_programs/sieve.py`.


Локализация: строка 4 исходного файла.

Предлагаемый patch:

```diff
--- a/python_programs/sieve.py
+++ b/python_programs/sieve.py
@@ -1,7 +1,7 @@
 def sieve(max):
     primes = []
     for n in range(2, max + 1):
-        if any(n % p > 0 for p in primes):
+        if not primes or any(n % p > 0 for p in primes):
             primes.append(n)
     return primes
```
