# Расстояние Левенштейна


## Шаг 1 Исходный код QuixBugs

```python
def levenshtein(source, target):
    if source == '' or target == '':
        return len(source) or len(target)

    elif source[0] == target[0]:
        return 1 + levenshtein(source[1:], target[1:])

    else:
        return 1 + min(
            levenshtein(source,     target[1:]),
            levenshtein(source[1:], target[1:]),
            levenshtein(source[1:], target)
        )
```

Файл: `python_programs/levenshtein.py`. Номера строк замечаний относятся к полному исходному файлу; копия сохранена в `data/QuixBugs/python_programs/levenshtein.py`.

## Шаг 2 Что проверяющий знает об ошибке

Совпадающие символы ошибочно увеличивают расстояние на 1.

Наглядный вход: `levenshtein('a', 'a')`. Ожидается `0`. Это поясняющий пример, а A/T/R ниже рассчитаны по тестам из зафиксированного манифеста.

В манифесте: 5 целевых и 1 регрессионных тестов. Эталон и тесты служат материалами оценивания.
