Пакет содержит 20 подготовленных ответов, 40 учебных оценок и результаты фактического выполнения тестов на подготовленных патчах. Gemma и Qwen-Coder — условные названия двух групп ответов. Происхождение материалов описано в [паспорте данных](Паспорт%20данных.md).

## Повторение

Установите зависимости и загрузите снимок, как описано в [README репозитория](../../README.md). Из корня репозитория выполните:

```sh
python -m examples.quixbugs10.replay
```

Скрипт повторно проверяет JSON, точное применение diff и синтаксис, затем пересчитывает метрики по сохранённым тестовым исходам и учебным записям. Он обновляет отчёты и файлы в `results/`. У исторических протоколов пути к пользовательскому каталогу заменены на `$USERPROFILE`.

Для повторного запуска тестов доверенных подготовленных патчей используйте `python -m examples.quixbugs10.replay --recheck-tests`. Этот режим сохраняет новые журналы в `results/recheck/`.
