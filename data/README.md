# Техническая выборка QuixBugs

`manifest.jsonl` и `dataset_manifest.csv` описывают 40 задач из одного исходного репозитория. У 31 задачи в зафиксированном окружении есть прошедший эталон, хотя бы один целевой тест и хотя бы один регрессионный тест. Статус отбора и методика приведены в [документации конвейера](../docs/pipeline.md). Выборка обслуживает технические проверки v8.

Скрипт `python tools/fetch_quixbugs.py` получает нужные файлы из архива коммита `4257f44b0ff1181dedaedee6a447e133219fcebf` и проверяет каждый файл по `provenance.json`. Данные появятся в `data/QuixBugs/`. Для работы с уже скачанным ZIP-архивом передайте его путь через `--archive`. Скрипт воспроизводит исходные окончания строк там, где они влияют на контрольные суммы.
