# Полный тестовый пример датасета CCRQS

**Весь пример вымышленный.** Исходник, модель, эксперты, результаты тестов, временные отметки и оценки придуманы. Модель и тесты не запускались, сведения с внешними источниками не сверялись. Все записи помечены `synthetic: true`, весь набор — `research_eligible: false`. Хеши вычислены при записи файлов для внутренней согласованности.

Полный набор всех полей находится в [dataset.json](dataset.json). Те же записи разложены по таблицам в `tables/`. Здесь показан весь сценарий в читаемом виде.

## 1. Первоначальные данные

| Поле | Значение |
|---|---|
| Источник | Fictional Python Bugs, выпуск `demo-2026-11` |
| ID примера | `example-demo-average-v1` |
| Группа репозитория | `fictional/math-utils` |
| Язык | Python |
| Файл | `src/math_utils.py` |
| Назначение | Только синтетическая демонстрация; без исследовательского разделения |

Исходный [код с ошибкой](artifacts/buggy/src/math_utils.py):

```python
def average(values):
    return sum(values) / len(values)
```

Разрешённый контекст для модели: «Для непустого списка чисел вернуть среднее, включая отрицательные числа; для пустого списка вызвать ValueError».

Оценочные материалы хранятся отдельно в `reference_data`:

- Основной дефект: `average([])` вызывает `ZeroDivisionError` вместо `ValueError`; файл `src/math_utils.py`, строка 2, категория `runtime`.
- [Эталонное исправление](artifacts/reference/src/math_utils.py) добавляет проверку пустого списка перед делением.
- [Целевой тест и три регрессионных теста](artifacts/tests/test_math_utils.py) задают пустой, положительный, отрицательный и одноэлементный ввод.
- [Лицензионное описание примера](artifacts/LICENSE.txt) относится к вымышленному учебному коду.

## 4. Схема оценки и экспертные пакеты

[Схема оценки `rubric-demo-full-v1`](artifacts/rubric.json) содержит формы, шкалы, правила независимости и предъявления. Это заполненная демонстрационная форма на основе проекта v6; она не утверждает протокол диплома.

Все четыре пакета материализованы в отдельных JSON. Их содержимое и хеши записаны также в `expert_packets`:

| Пакет | Что видит эксперт | Чего нет в предъявляемом содержимом |
|---|---|---|
| [M](artifacts/packets/M.json) | Код, контракт, основной дефект, комментарий | Patch, модель, confidence/severity, тестовые исходы, чужие оценки |
| [C](artifacts/packets/C.json) | Код, контракт, основной дефект, выбранный комментарий | Patch и служебные результаты |
| [S](artifacts/packets/S.json) | Код, ожидаемое поведение, patch модели | Эталонный patch, тестовые исходы и служебные результаты |
| [H](artifacts/packets/H.json) | Код, контракт, всё замечание с patch | Эталонное описание дефекта и служебные результаты |

Полный `dataset.json` предназначен исследователю. Эксперту предъявляется только содержимое соответствующего пакета.

## 6. Разногласие и арбитраж

В [adjudications.jsonl](tables/adjudications.jsonl) находится решение `adjudication-demo-001`:

- Вход: три исходные оценки M — `primary_match`, `primary_match`, `false_positive`.
- Арбитр: `expert-demo-07`.
- Итог: `primary_match` для замечания 0.
- Причина: контракт явно включает пустой ввод; третья оценка основана на неверном предположении.

Первичный ответ эксперта 03 остаётся `false_positive`. Итог арбитра хранится отдельной записью со ссылками на все три ответа.

## 7. Итоговый расчёт

В [metric_config.json](artifacts/metric_config.json) заданы **иллюстративные** формулы и веса только для этого примера. Они не являются утверждёнными весами диплома.

| Показатель | Расчёт | Значение |
|---|---|---|
| D | 2×TP / (2×TP+FP+FN), TP=1, FP=0, FN=0 | 1 |
| C | Сумма медиан трёх признаков / 6 | (2+2+1)/6 = 0.833333… |
| S | Медиана 1, 1, 1 | 1 |
| Q | A×T×R×S | 1 |
| H | Медиана независимых 3, 4, 3 | 3 |
| CCRQS | 0.4×D + 0.3×C + 0.3×Q | **0.95** |

Запись [metric_results.jsonl](tables/metric_results.jsonl) содержит ссылки на автоматическую проверку, все двенадцать экспертных ответов, решение арбитра, версию схемы оценки и конфигурацию расчёта. Независимая H хранится отдельно от компонентов CCRQS.
